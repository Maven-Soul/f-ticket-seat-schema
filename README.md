# FPass Scheme Studio

Отдельный редактор интерактивных схем FPass. Он не использует Laravel, Inertia,
базу данных или сессию административной панели: результат работы — JSON-файл
формата `fpass-seat-map` версии 2.

## Запуск

```bash
npm install
npm run dev
```

Studio будет доступна по адресу `http://localhost:5174`.

## Работа со схемой

1. Укажите название и при необходимости группу шаблонов.
2. Создайте схему в редакторе.
3. Нажмите «Экспорт JSON».
4. В административной панели откройте «Схемы продаж» и загрузите файл кнопкой
   «Загрузить JSON-схему».

После загрузки платформа создаёт интерактивную схему; доступ организаторам
назначается стандартным механизмом доступа к схемам в административной панели.
